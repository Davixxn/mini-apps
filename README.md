# mini-apps

작고 독립적인 바닐라 HTML/CSS/JS 미니 앱 모음입니다. 각 폴더는 빌드 없이 브라우저에서 `index.html`을 바로 열어 실행할 수 있습니다.

## Apps

- [`pomodoro-todo`](pomodoro-todo/index.html) — 포모도로 타이머 + 할 일 목록 (localStorage에 세션/할 일 저장)
- [`neon-snake`](neon-snake/index.html) — 방향키/WASD로 조작하는 네온 스타일 스네이크 게임
- [`kaleidoscope-pad`](kaleidoscope-pad/index.html) — 대칭 패턴으로 그리는 만화경 드로잉 패드

## Run

각 앱 폴더의 `index.html` 파일을 브라우저에서 열면 됩니다. 별도의 설치나 빌드 과정이 필요 없습니다.
